# 一般ユーザー向け PassoFlow ガイド

このガイドは、YAMLを直接編集せずに PassoFlow を画面から操作する方向けです。アクションを選び、値を入力し、保存して実行するまでの流れを説明します。

## まずここから

最初のシナリオは、次の順番で作ります。

1. シナリオを開くか、新しく作成します。
2. 左のアクションをクリックするか、キャンバスへドラッグして追加します。
3. アクションを選択し、右のパネルで必須項目を入力します。
4. シナリオを保存してから、実行ボタンを押します。
5. 期待どおりにならない場合は、実行ログを確認します。

## 画面の見方

画面左のアクションパネルから操作したいアクションを探し、中央のキャンバスに配置します。右のプロパティパネルでは、選択したアクションの値を設定します。画面下の実行ログ、変数一覧、取り込んだデータで実行結果を確認できます。

## フローを作る

1. 左の検索欄で、やりたい操作を検索します。「ボタンをクリック」「文字を入力」のように目的から探すと見つけやすくなります。
2. アクションをキャンバスへドラッグします。クリックして、選択中のアクションの直後に追加することもできます。
3. 追加されたノードを選択し、右のプロパティパネルで必須項目を入力します。
4. ノードをドラッグして配置を整えます。接続線の矢印で実行順を確認できます。

通常は上から下へ処理を並べます。最初は小さなフローから始め、1つの操作が動くことを確認してから、ループ、条件分岐、表データを追加します。

## よく使う操作

- ボタンやメニューを操作する: 画面の対象をスクリーンショットとして登録し、画像をクリックするアクションを使います。
- 文字を入力する: 入力欄をクリックするアクションの後に、文字入力アクションを配置します。
- アプリを起動する: アプリ起動、待機、ウィンドウをアクティブ化するアクションを順番に配置します。
- 条件で処理を分ける: 条件分岐を配置し、true と false の枠の中にそれぞれの処理を置きます。

## Excel / CSV のデータを使う

画面下の「取り込んだデータ」から Excel または CSV を取り込みます。取り込んだ直後は全行にチェックが入り、チェックを外した行は実行時にスキップされます。取り込んだデータは「開始」から「終了」までの処理に順番に渡されます。

## 保存して実行する

1. メニューの「保存」または Ctrl+S でシナリオを保存します。
2. 実行ボタンを押します。
3. 実行ログで、実行前チェックの結果と各アクションの結果を確認します。
4. 画像やウィンドウが見つからない場合は、ログに表示されたアクションの画像、待機時間、リトライ回数を見直します。

アクションを増やす前に、現在のステップが動くことを確認してください。画像認識やウィンドウの前面化で問題が起きた場所を見つけやすくなります。

## さらに詳しく知りたい方へ

YAMLファイルを直接編集したい方、全アクションのパラメータや変数・ループ・分岐の仕様を確認したい方は、[上級者向け YAML / アクションリファレンス](/docs/manual?lang=ja&audience=advanced) を参照してください。

## ブラウザ操作方式

ブラウザフローごとに、次のどちらかを選びます。

- 画面画像方式: `open_url` の後に `activate_window` と `click_image` などを使います。
- DOM 方式: Playwright で制御するブラウザを `browser_navigate`、`browser_click`、`browser_fill`、`browser_wait_for` と CSS セレクタで操作します。

DOM 方式を使う前に `python -m playwright install chromium` を一度実行してください。
